# 应用项目
- `H5->h5_project>mddactivity->buyTemplateNew`

## 上报参数
### logData
- **performance（性能参数对象，重要）**：
    - **LCP**：页面最大最显眼的图片加载时间，这里加载时机获取的是真正该图片 `onload` 的时间，而不是预加载完毕时间。需注意在 `webView` 里面预加载的时间不等于图片预加载的时间，这是因为 `webView` 的图片渲染需要在所有的资源加载完再开始渲染。
    - **FP**：白屏时间（`html` 中 `head` 加载完毕，`JS` 开始运行/元素开始渲染的时间）。
    - **VueMounted**：`vue` 框架 `mounted` 时间。
    - **domAllRender**：页面元素都渲染完的时间（包括图片及其余第三方资源），相当于 `load` 时间。
    - **domContentRender**：页面节点元素渲染完的时间（`dom`，`css`），相当于 `contentLoad` 时间。
    - **load**：页面所有资源加载完毕时间，与 `domContentRender` 基本一致。
    - **timeAverage**：一秒内收集的帧平均渲染时间（实验参数，60fps 运行下平均一帧是 16.7ms，按照这个标准下计算的平均一帧渲染时间，当这个时间较大时，说明页面渲染可能出现卡顿）。
    - **timeThan100Percent**：一秒内收集的超过 100ms 的帧渲染时间占所有收集帧渲染时间的百分比，对于收集在不同硬件（高低性能手机）下打开 `H5` 时候是否流畅有实验观察价值，一般人类感觉到舒适的动画效果是 60 帧也就是 60FPS，换算下来就是 16.7ms 一帧，当页面渲染一帧的时间过高就会出现卡帧，导致动画不流畅造成体验感问题。
    - **ttfb**：后端接口与前端项目传送一个字节信息的时间。
- **system（硬件参数，与之前业务打点上报参数基本一致）**：

## 上报时机
- 上报的时机是在拿到 `LCP` 加载完毕时间之后的 1 秒后再去执行上报函数，上报函数会监听页面所有元素加载完毕（`load` 事件）之后再去上报，防止页面渲染阻塞，最后做了一个兜底处理，若未能捕获 `load` 事件，则在 3 秒后再去上报。

### 监听 LCP onload 时间
```javascript
LCPTime(newVal, oldVal) {
    if (newVal &&!oldVal) { //第一次渲染完毕时性能收集
        setTimeout(() => {
            this.runMddPerformace();
        }, 1000)
    }
}
```

### 性能收集函数
```javascript
const runMddPerformace = () => {
    // 此处省略部分代码逻辑，主要相关逻辑如下
    window.addEventListener('load', () => {
        getPerformanceCb()
    })
    // 防止load未被监听到的兜底
    setTimeout(() => {
        console.log(getLoad, 'getLoad');
        if (!getLoad) {
            getPerformanceCb()
        }
    }, 3000)
}
```

### 帧率收集相关
帧率收集的数据获取在 `html` 层也就是白屏时间即开始计算，为求达到可以收集到页面一进来对于页面的渲染最真实的实际情况。相关代码如下：
```html
<script type="text/javascript">
    var measureTime;
    const getMeasure = () => {
        let lastTime = 0; //记录上一次的时间
        let initTime = Date.now();//初始时间
        let initRAF;//requestAnimationFrame函数
        let timeNum = 0 //1秒内收集的渲染时间,60FPS的标准时间为16.7ms
        let timeTotal = 0 //收集1秒内所有的渲染时间和,用于计算平均渲染时间
        let time100Num = 0//1秒内收集到超过100ms的渲染时间,这些代表画面渲染卡顿
        let timeThan100Percent;//1秒内渲染超过100ms占收集数据的百分比,超过20%算是不及格
        let timeAverage; //1秒内收集到的渲染时间数的平均数
        return new Promise((resolve, reject) => {
            const frame = () => {
                const currentTime = Date.now();
                if (currentTime - initTime < 1000) {
                    const time = currentTime - lastTime;
                    if (lastTime) {
                        timeNum++;
                        timeTotal += time;
                        if (time > 100) {
                            time100Num++;
                        }
                    }
                    lastTime = currentTime;
                    initRAF = requestAnimationFrame(frame);
                    console.log('继续');
                } else {
                    cancelAnimationFrame(initRAF);
                    if (!time100Num &&!timeNum) {
                        timeThan100Percent = '0%'
                        timeAverage = '0ms'
                    } else {
                        timeThan100Percent = (time100Num / timeNum * 100).toFixed(2) + '%';
                        timeAverage = (timeTotal / timeNum).toFixed(2) + 'ms';
                    }
                    console.log(timeNum, time100Num, timeThan100Percent);
                    console.log(timeTotal / timeNum);
                    console.log('结束');
                    resolve({
                        timeThan100Percent,
                        timeAverage
                    });
                }
            };
            frame(); // Start the animation frame loop
        });
    }
    const getMeasureTime = async () => {
        measureTime = await getMeasure()
        console.log(measureTime);
    }
    getMeasureTime()
</script>
```
