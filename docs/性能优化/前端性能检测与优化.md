### 前端性能检测
1. **使用浏览器固有插件**：
    - **network**：
        - 体积大小，gzip 压缩；
        - 加载顺序，时间；
        - http 缓存，http 版本；
        - css 文件是否单独提取；
        - 静态资源是否压缩，使用正确格式，是否使用 CDN。
    - **Coverage**：
        - 观测代码执行的覆盖率，有利于分包。
2. **使用专业检测工具**，lighthouse，**webPageTest**（后者会比前者更好，后者对于 H5 测量准确性更高，而且可以选择测试节点）：
    - 查看性能指标，FCP，LCP，资源加载时间，顺序。
3. **项目代码**：
    - **config.js 配置文件**：
        - 查看是否合理使用 loader，plugins：
            - 是否合理分包；
            - 是否单独抽离文件如 css 文件；
            - 是否执行文件压缩；
            - 是否去除冗余代码；
        - 是否使用合理抽离打包 JS 模块，使用 CDN 加载：
            - 可以领用 --report 去查看打包生成出来的模块集成图。
    - **html 层**：
        - 是否注意阻塞问题使用 script 标签的 async，defer 属性；
        - 是否使用骨架屏，loading 过度白屏；
        - 是否使用静态资源预加载预渲染。
    - **框架层**：
        - 有没有使用懒加载（模块懒加载，资源懒加载等）。
4. **项目在浏览器运行**：
    - 查看是否有骨架屏，loading 过度；
    - 是否卡帧（performance 检测）。
