# 骨架屏方案

## `draw-page-structure`介绍
此方案适用所有前端 MVVM 项目，其原理如下：
- 利用 Puppeteer 去爬取页面节点；
- 根据配置生成对应的骨架节点；
- 插入到指定的标签。

## 使用方法（以 vue 作为案例）
1. **全局安装插件**
   首先全局安装插件 `draw-page-structure`，这个插件要依赖 Puppeteer，执行命令：
```bash
pnpm i draw-page-structure -g
```
2. **初始化配置文件**
   安装完之后，进入到项目目录下首先初始化 `dps.config.js` 配置文件，执行命令：
```bash
dps init
```
3. **启动无头浏览器及相关操作**
   执行命令启动无头浏览器，执行对应的脚本，读取 `dps.config.js` 然后就会生产一个 html 片段插入到对应的 `.html` 文件中，执行命令：
```bash
dps start
```

## `dps.config.js`配置介绍
以下是 `dps.config.js` 的配置示例及相关说明：
```javascript
const path = require('path');
const filepath = path.resolve(__dirname, './index.html');

const dpsConfig = {
    url: 'http://localhost:8080/vodactivity/serviceOpt/#/',      // 待生成骨架屏页面的地址，用百度（https://baidu.com）试试也可以
    output: {
        filepath,   // 生成骨架屏的存放页面，一般为项目的入口页面
        injectSelector: '#app'  // 生成的骨架屏插入页面的节点
    },
    // background: '#ecf0f2',
    animation: 'opacity 1s linear infinite;',
    includeElement: function(node, draw) {
        // 定制某个节点画出来的样子，带上return false
        // if(node.id == 'ui-alert') {
        // 跳过该节点及其子节点
        // return false;
        // }
        if(node.classList.contains('menu_title')) {
            const {t, l, w, h} = getRect(node);
            draw({
                width: wPercent(w),
                height: hPercent(h/2),
                top: hPercent(t),
                left: wPercent(l),
                // radius:'50%'   // 注意，这里是radius而不是boderRadius，我是看了源码才知道的
            });
            return false;
        }

    },
    // writePageStructure: function(html) {
    // 自己处理生成的骨架屏
    // fs.writeFileSync(filepath, html);
    // console.log(html)
    // },
    init: function() {
        // 生成骨架屏之前的操作，比如删除干扰节点
        // 比如删除干扰节点
        let btnBox = document.querySelector('.btnBox');
        let title = document.querySelector('.title');
        if(btnBox) {
            btnBox.parentNode.removeChild(btnBox);
        }
        if(title) {
            title.style.visibility = 'hidden';
        }
        // 比如适当的调整某个节点的样式
        // let specil = document.querySelector('.specil');
        // specil.style.visibility = 'hidden';
    }
}

module.exports = dpsConfig;
```
### 相关函数说明
- **`getRect(node)`**：
  返回: `{ w,h,t,l}` ，分别表示 `width`、`height`、`top`、`left`。
- **`wPercent(x)`**：
  返回：节点宽度占总宽度的百分比。
- **`hPercent(y)`**：
  返回：节点高度占总高度的百分比。
- **`getStyle(node,attr)`**：
  返回：节点的属性值。
