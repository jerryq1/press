# 实战1:创建项目-NFT

## 创建项目

要开始一个新的 Foundry 项目，您首先需要在终端中运行以下命令来初始化项目：

```bash
forge init hello_foundry
```

这个命令会创建一个名为 `hello_foundry` 的新目录，并设置好所有必要的文件结构，为开发智能合约提供基础。

## 查看项目结构

初始化项目后，我们可以查看项目的文件夹结构。进入项目目录，并使用 `tree` 命令来展示目录结构的第一层：

```bash
cd hello_foundry
tree . -d -L 1
```

输出结果将显示如下目录结构：

```
.
├── lib
├── script
├── src
└── test
```

- **lib/**: 存放项目依赖的库文件。
- **script/**: 包含可以执行的脚本，这些脚本通常用于部署或与已部署的合约交互。
- **src/**: 源文件夹，其中包含智能合约的 Solidity 源代码。
- **test/**: 测试文件夹，包含用于测试智能合约的脚本。

## 编译项目

在项目正确设置后，下一步是编译智能合约。在项目根目录下运行以下命令：

```bash
forge build
```

这个命令将编译 `src` 目录中的所有 Solidity 文件，确保合约无编译错误，并准备好进行下一步的测试。

## 测试合约

Foundry 提供了一个强大的测试框架，使得测试智能合约变得简单。确保你已经在 `test` 目录下编写了测试脚本后，运行以下命令来执行测试：

```bash
forge test
```

此命令将执行所有的测试用例，验证合约的功能是否按预期工作。通过这些步骤，您不仅能确保合约的基本功能，还能通过测试结果及早发现和修复潜在问题。

通过以上步骤，我们就顺利创建、编译并测试自己的 Foundry 项目，为后续的开发和部署打下基础。
