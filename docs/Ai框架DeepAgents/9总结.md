# 总结

## 1. DeepAgent智能体创建

```
deep_agent = create_deep_agent(
    model = 配置模型,
    system_prompt = 系统提示词,
    tools = [],
    subagents = [],
    checkpoint = 检查点 短期记忆 MemorySaver(),
    interrupt_on = [], 人机交互
    backend = 长期记忆 State Store FileSystem Composite ...,
    store = 存储长期记忆的工具,
    middleware = [自定义, 现有的中间件], 中间件
    skills = ["skill在fileBackend下的文件夹地址"] 外置技能
)
```

> 💡 生活比喻：创建DeepAgent就像组建一个团队——model是队长，tools是工具箱，subagents是手下小组，checkpoint是便签纸，backend是档案室，middleware是审批岗，skills是外聘专家的技能手册。

---

## 2. 执行和结果处理

同步: invoke | stream

异步:
   invoke | astream -> async

处理结果:

   invoke => result['messages'][-1].content

   stream => key -> tools(调用了工具) | model(调用工具和子智能体或者直接返回结果) : {messages: []}

> 💡 生活比喻：invoke像点外卖一次性送到，stream像堂食一道道上菜。异步(ainvoke/astream)就像点完餐先干别的事，做好了再通知你。

---

## 3. 兼容Langgraph和LangChain

如何创建子智能体：字典 | CompiledSubAgent

字典:

    deepagent -> subagent -> {model, description, system_prompt, tools, checkpointer, interrupt_on, middleware, skills}
对象:

    CompiledSubAgent -> langchain langgraph 

    CompiledSubAgent(name, description, runnable = langchain/langgraph)
注意:

    langgraph compile() state -> messages 属性

> 💡 生活比喻：子智能体就像手下的专员。字典方式像口头交代需求，CompiledSubAgent方式像正式任命一个有岗位说明书的员工。

---

## 4. 人机交互实现HITL

最佳实践：
1. 必须配置短时间记 checkpoint = MemorySaver() 必须配置线程id invoke( config = thread_id )
2. interrupt_on = {key=工具名 : value True 交互 | False 直接放行 }，人机交互
3. 预先执行一次 result = invoke() 触发了人机交互，本次不会真的执行
4. 获取拦截和交互状态 result['__interrupt__']['0'].value => {action_requests :[{name , args }],{}} | review_config}
   type: reject,
   type: approve,
   {type: edit, edited_action:{name: 工具名,args:{参数名:新的参数}}}
5. 再次执行，真的执行 result = invoke(Command(resume = {"decisions": []}),config = 上一次的线程id)

> 💡 生活比喻：HITL就像公司的审批流程——提交申请，领导审批（同意/拒绝/修改），然后拿着结果去执行。

---

## 5. 记忆（长短期）

短期：一次执行的过程 checkpoint = MemorySaver() 人机交互

长期：执行的最终结果 store backend 跨会话进行数据共享

> 💡 生活比喻：短期记忆像便签纸（记当前任务），长期记忆像档案室（跨会话共享）。

---

## 6. 中间件

自定义中间件：@wrap_tool_call 函数(request,handler) 前置增强 handler(request) 后置增强 return xx

现成的中间件：SummarizationMiddleware( ModelCallLimitMiddleware( ToolCallLimitMiddleware( behavior = end | error middleware = [自定义,现有的中间件] 

> 💡 生活比喻：中间件像机场安检——前置增强（身份验证），核心逻辑（登机），后置增强（海关检查），多个中间件组成过滤器链。

---

## 7. skill和配置

理解跨skill -> 技能 -> 提示词复用 -> 文件夹（name） / SKILL.md 元数据 yaml | 提示词 md

deepagent -> skill 1. fileSystemBackEnd 2. skills = ["file的下面的文件夹的 skills "]

skill加载原理 -> 渐进式 -> 元数据 -> 加载提示词 -> 实现功能

> 💡 生活比喻：Skill就像岗位操作手册——每个技能对应一个文件夹，里面有元数据（什么场景用）和提示词（怎么做），需要时翻看执行。
