# 重点4:Vue3响应式回顾


## 功能特性
- **Proxy对象实现属性监听**


- **多层属性嵌套处理**  
  在访问属性过程中，能够动态处理下一级属性：
  - Vue 2.x：初始化时遍历每个属性，转化为响应式数据。
  - Vue 3：通过整个对象监听，访问到下一级属性（也是对象）时再进行监听。

- **动态属性监听**  
  默认支持动态添加的属性监听。

- **属性删除监听**  
  默认支持对属性删除操作的监听。

- **数组索引和length属性监听**  
  默认监听数组的索引变化和`length`属性的变更。

- **独立模块化支持**  
  可作为单独的模块使用。

---

## 核心方法

### reactive
用于将对象转化为响应式数据。

### ref
创建一个持有单一值的响应式对象。

### toRefs
将响应式对象的属性解构为多个独立的`ref`对象。

### computed
创建一个计算属性，基于依赖自动计算值。

### effect
用于定义副作用函数，观察响应式状态的变化。

---

## 依赖追踪与更新

### track
收集依赖，当响应式对象的属性被访问时触发。

### trigger
触发更新，当响应式对象的属性发生变化时调用。
