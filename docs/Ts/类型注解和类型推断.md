## 1. 变量类型注解

使用冒号（:）为变量显式指定类型。

```typescript
let name: string = "徐二狗";
let age: number = 18;
let isActive: boolean = true;
let scores: number[] = [90, 85, 88];
let user: { name: string; age: number } = { name: "鱼皮", age: 18 };
```

## 2. 函数参数和返回值类型注解

### 2.1 函数参数类型注解

为函数参数添加类型注解，确保传入正确的参数类型。

```typescript
// 基础参数类型注解
function greet(name: string): void {
    console.log(`Hello, ${name}!`);
}

// 多个参数类型注解
function add(a: number, b: number): number {
    return a + b;
}

// 对象参数类型注解
function printUser(user: { name: string; age: number }): void {
    console.log(`${user.name} is ${user.age} years old`);
}

// 可选参数（使用 ? 标记）
function greetUser(name: string, greeting?: string): string {
    if (greeting) {
        return `${greeting}, ${name}!`;
    }
    return `Hello, ${name}!`;
}

// 默认参数
function createUser(name: string, age: number = 18): object {
    return { name, age };
}
```

### 2.2 函数返回值类型注解

为函数返回值添加类型注解，确保函数返回正确的类型。

```typescript
// 明确指定返回值类型
function getUserName(): string {
    return "鱼皮";
}

// 返回 void（无返回值）
function logMessage(message: string): void {
    console.log(message);
}

// 返回联合类型
function getValue(isNumber: boolean): string | number {
    return isNumber ? 42 : "四十二";
}

// 返回 Promise 类型
function fetchData(): Promise<{ id: number; name: string }> {
    return Promise.resolve({ id: 1, name: "鱼皮" });
}

// 返回 never（永不返回）
function throwError(message: string): never {
    throw new Error(message);
}
```

## 3. 类型推断

TypeScript 根据上下文自动推断变量和函数的类型，无需显式注解。

### 3.1 变量类型推断

```typescript
// 根据初始值自动推断类型
let name = "鱼皮";      // TypeScript 推断为 string
let age = 18;          // 推断为 number
let isStudent = true;  // 推断为 boolean
let scores = [90, 85, 88];  // 推断为 number[]

// 对象自动推断
let user = {
    name: "鱼皮",
    age: 18
};  // 推断为 { name: string; age: number }

// 数组自动推断
let mixed = [1, "hello", true];  // 推断为 (string | number | boolean)[]
```

### 3.2 函数返回值类型推断

TypeScript 根据 return 语句自动推断函数的返回值类型。

```typescript
// 自动推断返回值类型为 number
function add(a: number, b: number) {
    return a + b;
}

// 自动推断返回值类型为 string
function getGreeting(name: string) {
    return `Hello, ${name}!`;
}

// 自动推断返回值类型为 string | number
function getConditionalValue(flag: boolean) {
    if (flag) {
        return "success";
    }
    return 42;
}

// 没有 return 语句，自动推断为 void
function log(message: string) {
    console.log(message);
}
```

### 3.3 上下文类型推断

TypeScript 根据上下文（如赋值、函数调用等）推断类型。

```typescript
// 根据上下文推断参数类型
window.onclick = function(event) {
    // event 被自动推断为 MouseEvent
    console.log(event.clientX, event.clientY);
};

// 数组方法中的回调参数推断
const numbers = [1, 2, 3, 4, 5];
numbers.forEach((num, index) => {
    // num 推断为 number，index 推断为 number
    console.log(num, index);
});
```
