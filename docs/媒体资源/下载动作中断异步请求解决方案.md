# 下载动作中断异步请求解决方案

最近在做一个AI换脸下载H5发现有一个情况,当进行js下载动作时,当前正在执行的一部请求会被该动作终端,这导致一些延时埋点会请求失败

## 解决方法
使用async、await保证异步请求已经完毕再去执行下载动作

## 代码展示
```js
/**
 * @Description 下载准备
 * @param {}
 * @return {}
 * @author Jerry
 * @date 2025/10/29
 */
async downloadReady() {
  if (this.downloading) return;
  this.downloading = true
  let jobId = getQueryString('jobId')
  try {
    // 等待打点请求完成
    await this.trace({action: 'h5_vod_download_click', label: `${jobId},-1`});
  } catch (error) {
    console.error('打点失败:', error);
    // 即使打点失败也继续执行下载
  }
  if (isAndroid && isWeChat) {
    //特殊处理
    this.show = true
    return
  }
  if (!isWeChat) {
    this.downloadMP4()
    return
  }
  if (isAndroid && isWeChat) {
    //特殊处理
    this.show = true
  } else {
    this.downloadMP4()
  }
},
async downloadMP4() {
  // 创建一个隐藏的 < a > 标签
  // 下载行为会打断异步请求,所以这里得下载动作需要先打完点再执行
  const a = document.createElement('a');
  a.href = this.videoUrl;
  a.download = 'video.mp4'; // 设置默认文件名

  // 触发点击事件
  document.body.appendChild(a);
  a.click();

  // 清理
  document.body.removeChild(a);
  this.downloading = false
}
```
