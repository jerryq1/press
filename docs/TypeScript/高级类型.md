# TypeScript 高级类型 (Advanced Types) 详解

高级类型是 TypeScript 区别于其他静态语言的魅力所在。这些类型操作符使我们能够在类型层面进行编程，极大增强了系统的灵活性和类型安全。

## 1. 映射类型 (Mapped Types)

映射类型可以将一个旧的类型以某种方式转换成一个新类型。例如将所有属性变为可选。

```typescript
type Readonly<T> = {
    readonly [P in keyof T]: T[P];
};

interface User {
    name: string;
    age: number;
}

// 映射结果
type ReadonlyUser = Readonly<User>;
```

**【面试口白】**：
> "映射类型是 TypeScript 类型编程的基石。通过 `in keyof` 语法，我们可以高效地重用接口结构，比如将一个对象的所有字段都变为可选的或只读。它是实现内置工具类型（如 `Partial`, `Readonly`）的底层原理。"

---

## 2. 条件类型 (Conditional Types)

这种类型根据类型检查的结果，在两种类型中选择一种。

```typescript
// T extends U ? X : Y
type NonNullable<T> = T extends null | undefined ? never : T;

type StrOrNum = string | number | null;
type SafeStrOrNum = NonNullable<StrOrNum>; // string | number
```

**【面试口白】**：
> "条件类型好比 TypeScript 里的 `if-else`。它是通过 `extends` 关键字进行判断的，在处理泛型和复杂 API 时非常强大。另外，结合 `infer` 关键字，它可以让我们提取出泛型内部的类型细节。"

---

## 3. 索引类型 (Index Types)

索引类型包含 `keyof` (索引类型查询操作符) 和 `T[K]` (索引访问操作符)。

```typescript
function getProperty<T, K extends keyof T>(obj: T, key: K) {
    return obj[key];
}

let x = { a: 1, b: 2, c: 3 };
getProperty(x, "a"); // OK
// getProperty(x, "m"); // ❌ 错误: 参数类型 "m" 不存在
```

**【面试口白】**：
> "索引类型提供了一种捕捉动态对象属性的能力。`keyof` 就像反射一样拿到一个对象的所有键组成的联合类型，而 `obj[key]` 语法配合泛型能确保我们拿到的值具有正确的类型推断。"

---

## 4. 模板字面量类型 (Template Literal Types)

建立在字符串字面量类型的基础上，通过组合产生新的字符串类型。

```typescript
type World = "world";
type Greeting = `hello ${World}`; // "hello world"

type Size = "small" | "medium" | "large";
type Color = "red" | "blue";
type ProductID = `${Size}-${Color}`; // "small-red" | "small-blue" | ...
```

**【面试口白】**：
> "模板字面量类型极大地扩展了字符串字面量的表达力。它尤其适用于处理那些带有固定后缀或前缀的字符串（比如 CSS 属性或事件名称）。它能让代码在处理强约定的字符串拼接时依然保持类型感知。"
