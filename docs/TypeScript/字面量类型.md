# TypeScript 字面量类型 (Literal Types) 详解

字面量类型允许你指定一个变量必须具有的确切值。在 TypeScript 中，字面量类型通常与联合类型（Union Types）结合使用，以模拟枚举（Enums）的行为。

## 1. 字符串字面量类型 (String Literal Types)

字符串字面量允许你指定字符串必须具有的确切值。

```typescript
type Direction = 'North' | 'South' | 'East' | 'West';

function move(direction: Direction) {
    // ...
}

move('North'); // 正确
// move('Up'); // 错误: 类型 '"Up"' 的参数不能赋给类型 'Direction' 的参数
```

**【面试口白】**：
> "字符串字面量类型常用于限制变量的取值范围。相比于普通字符串，它在编译期就能捕捉到错误。通常我们会结合联合类型来替代简单的枚举，这让代码更轻量且易于维护。"

---

## 2. 数字字面量类型 (Numeric Literal Types)

数字字面量类型的工作方式与字符串字面量类型相同，只是它们针对的是具体数值。

```typescript
type DiceValue = 1 | 2 | 3 | 4 | 5 | 6;

function rollDice(val: DiceValue) {
    // ...
}

rollDice(3); // 正确
// rollDice(7); // 错误
```

**【面试口白】**：
> "数字字面量类型在处理特定的固定数值逻辑（如游戏状态、固定步长等）时非常有用。它能帮助开发人员更直观地理解代码逻辑中的取值约束。"

---

## 3. 布尔字面量类型 (Boolean Literal Types)

布尔字面量可以限制只能为 `true` 或 `false`。

```typescript
type TrueOnly = true;

// let isDone: TrueOnly = false; // 错误: 不能将类型 "false" 分配给类型 "true"
let isDone: TrueOnly = true; // 正确
```

**【面试口白】**：
> "虽然布尔字面量类型单独使用较少，但在条件类型（Conditional Types）或特定配置标识中，它能提供非常精确的控制。"
