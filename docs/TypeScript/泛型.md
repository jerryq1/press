# TypeScript 泛型 (Generics) 详解

泛型是指在定义函数、接口或类的时候，不预先指定具体的类型，而是在使用的时候再指定类型的一种特性。它是打造高复用代码的利器。

## 1. 泛型函数 (Generic Functions)

```typescript
function identity<T>(arg: T): T {
    return arg;
}

// 调用方式
let output1 = identity<string>("myString");
let output2 = identity(100); // 也是支持类型推断的
```

**【面试口白】**：
> "泛型函数允许我们在保持类型一致性的同时处理多种数据类型。相比于 `any`，泛型保留了输入和输出之间的类型联系，从而提供了更好的类型检查。"

---

## 2. 泛型接口与泛型类 (Generic Interfaces & Classes)

```typescript
// 泛型接口
interface Pair<T, U> {
    first: T;
    second: U;
}

const p: Pair<number, string> = { first: 1, second: "two" };

// 泛型类
class GenericNumber<T> {
    zeroValue: T;
    add: (x: T, y: T) => T;
}
```

**【面试口白】**：
> "泛型接口和类常用于容器结构（如 Repository、List、Response 结构）。它们定义了骨架，具体的业务负载则由调用方决定，极大增强了架构的灵活性。"

---

## 3. 泛型约束 (Generic Constraints)

我们可以通过继承一个接口来限制泛型必须满足某些条件。

```typescript
interface Lengthwise {
    length: number;
}

function loggingIdentity<T extends Lengthwise>(arg: T): T {
    console.log(arg.length); // 现在编译器知道它支持 .length 属性
    return arg;
}
```

**【面试口白】**：
> "泛型约束是必考点。它允许我们限制泛型的范围。通过 `extends` 关键字，我们可以确保传入的类型具备我们需要的特定属性或行为，而非漫无目的的 '任意类型'。"

---

## 4. 泛型工具类型 (Generic Utility Types)

TypeScript 内置了许多方便的工具类型。

| 工具类型 | 描述 |
| :--- | :--- |
| `Partial<T>` | 将 T 中的所有属性变为可选 |
| `Required<T>` | 将 T 中的所有属性变为必选（去掉 `?`） |
| `Readonly<T>` | 将 T 中的所有属性变为只读 |
| `Pick<T, K>` | 从 T 中挑选出一组属性 K |
| `Omit<T, K>` | 从 T 中剔除一组属性 K |

```typescript
interface User {
    id: number;
    name: string;
    email: string;
}

// 只要其中一部分
type UserIntro = Pick<User, 'name' | 'email'>;
// 不要 id
type UserWithoutId = Omit<User, 'id'>;
```

**【面试口白】**：
> "内置工具类型如 `Partial`, `Pick`, `Omit` 是处理接口转换的利器。在开发中，它们常用于处理 API 响应或组件 Props 的重用。理解它们的实现（通过映射类型 Mapped Types）是进阶 TypeScript 的关键。"
