# TypeScript 类型断言与类型守卫详解

在 TypeScript 中，有时我们比编译器更了解某个值的类型。类型断言和类型守卫提供了在运行时和编译时精确控制类型的方式。

## 1. 类型断言 (Type Assertion)

类型断言好比其它语言里的类型转换，但是不进行特殊的数据检查和解构。

- **`as` 语法（推荐）**
- **`<>` 尖括号语法（不推荐，在 JSX 中会有冲突）**

```typescript
let someValue: any = "this is a string";

// 使用 as 语法
let strLength: number = (someValue as string).length;

// 使用尖括号语法
let strLength2: number = (<string>someValue).length;
```

**【面试口白】**：
> "类型断言主要用于我们将 `any` 或联合类型转换为更具体的类型时。最常用的场景是处理 DOM 元素或第三方库返回的模糊类型。但需注意，断言只是告诉编译器 '相信我'，如果实际运行时类型不符，依然会报错，所以应谨慎使用。"

---

## 2. 类型守卫 (Type Guards)

类型守卫是一些表达式，它们执行运行时检查，以确保在特定的作用域内变量的类型。

### 2.1 typeof 类型守卫

用于原始类型（string, number, boolean, symbol）。

```typescript
function padLeft(value: string, padding: string | number) {
    if (typeof padding === "number") {
        return Array(padding + 1).join(" ") + value;
    }
    if (typeof padding === "string") {
        return padding + value;
    }
    throw new Error(`Expected string or number, got '${padding}'.`);
}
```

### 2.2 instanceof 类型守卫

用于类或实例。

```typescript
class Bird { fly() { console.log("flying..."); } }
class Fish { swim() { console.log("swimming..."); } }

function move(animal: Bird | Fish) {
    if (animal instanceof Bird) {
        animal.fly();
    } else {
        animal.swim();
    }
}
```

**【面试口白】**：
> "类型守卫是实现多态和安全处理联合类型的关键。`typeof` 适用于处理基础数据类型，而 `instanceof` 则专门用于判断对象的类归属。这确保了我们在逻辑分支内部访问的是安全的、已收窄的类型。"

---

## 3. 自定义类型守卫 (User-defined Type Guards)

可以使用 `is` 关键字来自定义类型守卫函数。

```typescript
interface Cat { meow(): void; }
interface Dog { bark(): void; }

// 自定义守卫：返回值必须是 "arg is Type" 格式
function isCat(pet: Cat | Dog): pet is Cat {
    return (pet as Cat).meow !== undefined;
}

function speak(pet: Cat | Dog) {
    if (isCat(pet)) {
        pet.meow(); // 这里 pet 被推断为 Cat
    } else {
        pet.bark(); // 这里 pet 被推断为 Dog
    }
}
```

**【面试口白】**：
> "自定义类型守卫通过 `is` 关键字将类型收窄的逻辑封装在函数中。这在处理复杂接口或属性存在性检查时非常有用，极大提高了代码的可读性和复用性。"
