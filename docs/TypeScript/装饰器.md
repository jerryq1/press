# TypeScript 装饰器 (Decorator) 详解

装饰器是一种特殊的类型声明，它可以被附加到类声明、方法、访问符、属性或参数上。装饰器使用 `@expression` 这种符号。

> **注意**：装饰器是一项实验性特性，需要在 `tsconfig.json` 中配置 `"experimentalDecorators": true` 开启。

## 1. 类装饰器 (Class Decorators)

由于它是附加到类上的，它可以用来观察、修改或替换类定义。

```typescript
function Greeter(target: Function) {
    target.prototype.greet = function(): void {
        console.log("Hello, there!");
    };
}

@Greeter
class GreetingService {}

let gs = new GreetingService();
(gs as any).greet(); // 输出: Hello, there!
```

---

## 2. 方法装饰器 (Method Decorators)

附加到方法上，可以获取该方法的属性描述符 `descriptor`。

```typescript
function Log(target: any, propertyKey: string, descriptor: PropertyDescriptor) {
    const originalMethod = descriptor.value;
    descriptor.value = function(...args: any[]) {
        console.log(`Calling ${propertyKey} with`, args);
        return originalMethod.apply(this, args);
    };
}

class Calculator {
    @Log
    add(a: number, b: number) {
        return a + b;
    }
}
```

---

## 3. 属性装饰器 (Property Decorators)

附加到属性上，常用于元数据记录或注入。

```typescript
function ReadOnly(target: any, propertyKey: string) {
    Object.defineProperty(target, propertyKey, {
        writable: false
    });
}

class User {
    @ReadOnly
    id: number = 100;
}
```

---

## 4. 参数装饰器 (Parameter Decorators)

附加到函数参数上。

```typescript
function Required(target: any, propertyKey: string, parameterIndex: number) {
    console.log(`Parameter at index ${parameterIndex} is required in ${propertyKey}.`);
}

class OrderService {
    process(@Required orderId: string) {}
}
```
